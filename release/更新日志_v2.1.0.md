## [2.1.0] - 2026-09-24

### 新增
- 新增「SRPatch」过签模式（移植 SRPatch X，PMS + IO + SVC 多层签名校验绕过），可选强度等级：
  - Lv.1 PMS Hook
  - Lv.2 IO + PMS Hook
  - Lv.3 增强 Hook
  - Lv.4 SVC Hook（默认，内核系统调用层拦截，绕过能力最强）
  - 仅支持 arm64-v8a
- 一键脱修支持自选过签方式：点「开始脱修」后弹窗选择
  - 原生（IO 重定向 + PM 代理）
  - SRPatch（选中后再选强度 Lv.1~4）
- 新增 Java 异常上报：在最外层安装异常转发处理器，确保 Java 崩溃也能上报 Bugly（此前 Java 异常被沙箱的全局处理器吞掉，只能收到 native 崩溃）

### 修复
- 修复内存脱壳 / 沙箱脱壳用 `sun.misc.Unsafe` 读野指针导致的 SIGSEGV 闪退：读取前先校验地址是否落在 `/proc/self/maps` 的可读区间内

### 优化
- 一键脱修过签引擎由写死改为用户可选，默认保持原「原生」行为
